## 👋 Sobre mim

Sou **Engenheiro de Qualidade** com formação em **Análise e Desenvolvimento de Sistemas (UNINOVE)** e **3+ anos** atuando entre **QA, automação e engenharia de software**.

Gosto de trabalhar onde qualidade realmente muda o jogo: **testes automatizados que pegam bugs cedo**, **pipelines que deixam o feedback rápido**, e **processos simples o suficiente para o time seguir sem sofrer**.

- **Foco:** Automação Web (E2E/UI) e API, qualidade contínua (CI/CD) e práticas ágeis  
- **Ferramentas:** Robot Framework, Cypress, Playwright, Selenium, Postman, GitHub Actions  
- **Linguagens:** JavaScript/Node.js, TypeScript, Java e Python  
- **Cloud/observabilidade:** AWS Lambda, CloudWatch (e boas conversas com logs quando algo dá ruim)

> 🎯 **Objetivo:** atuar com **QA Automation / Engenharia de Qualidade**, elevando cobertura, confiabilidade e velocidade de entrega.

## 🧭 O que eu faço no dia a dia

- Automação de **testes E2E, API, regressão e unitários**, cobrindo o fluxo completo (UI → API → DB)
- Validação de **integrações entre serviços** (REST e fluxos assíncronos quando aplicável)
- Apoio em investigação de incidentes com **AWS Lambda/CloudWatch**, logs e observabilidade
- Consultas e validações em **PostgreSQL** e **MongoDB** para garantir consistência e rastreabilidade
- Criação e evolução de **pipelines CI/CD** com **GitHub Actions** para feedback rápido e confiável
- Análise de risco, definição de cenários e colaboração próxima com dev/produto/negócio
- Participação em cerimônias ágeis com foco em melhoria contínua
